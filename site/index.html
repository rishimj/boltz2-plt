How a Per-Layer Transcoder works

Each of six Pairformer depths gets its own transcoder. It reads the single representation, keeps only the 16 strongest of 2,048 latents, and decodes them into the pair representation. Sparse latents are what make the features inspectable.

k

TopK sparsity

Only 16 of 2,048 latents survive per token, which forces each one to carry a specific, nameable concept instead of a blurred mixture.

↺

Dead-feature resurrection

Latents that stop firing are re-initialized toward high-error examples, so dictionary capacity is not wasted as training proceeds.

∞

Online multi-layer training

Activations are streamed from Boltz2 forward passes via hooks and six transcoders are trained side by side, deterministically (seed 42).

Run it for real

Training needs a CUDA GPU (24 GB+ recommended) and the Boltz2 checkpoint. Full instructions are in the README and the technical docs.

# clone + install
git clone https://github.com/rishimj/boltz2-plt.git && cd boltz2-plt
pip install boltz[cuda] -U torch pytorch-lightning einops einx
wget https://model-gateway.boltz.bio/boltz2_conf.ckpt -O boltz2_checkpoint.ckpt

# train six per-layer transcoders on streamed Boltz2 activations
cd transcoder
python universal_transcoder/train_online_multi_layer.py \
    --fasta-dir ../examples/multi_protein_split \
    --checkpoint-dir ./trained_plt_checkpoints \
    --layers 0 8 16 24 32 40 --epochs 20 --batch-size 10 --seed 42

# evaluate reconstruction R², sparsity and dead features
python validation_scripts/validate_multi_layer.py \
    --checkpoint-dir ./trained_plt_checkpoints --layers 0 8 16 24 32 40
