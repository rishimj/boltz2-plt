Interpretability for structural biology

What does a protein folding model actually learn?

Per-Layer Transcoders (PLT) are sparse autoencoders trained inside Boltz2, a state-of-the-art biomolecular structure predictor. They decompose each Pairformer layer into 2,048 sparse features, so helices, buried cores and long-range contacts become things you can point to.

Method

A sparse lens on every depth of the trunk

Boltz2's Pairformer refines a per-residue single representation and a residue-pair representation across 48 blocks. PLT hooks six of those blocks and learns an overcomplete, sparse dictionary for each one, reconstructing the pair signal from only 16 active features per residue.

6Pairformer blocks transcoded: 0, 8, 16, 24, 32, 40
384 → 2,048Single representation to sparse dictionary
k = 16Active features per residue (0.78%)
128Pair-representation channels decoded

01Hook the trunk

Forward hooks on six Pairformer blocks capture the single representation s and the pair representation z while Boltz2 predicts real protein structures.

02Learn a sparse dictionary

Each transcoder encodes 384-d activations into 2,048 latents and keeps the top 16. Unit-norm decoder columns and dead-feature resurrection keep the dictionary healthy.

03Name the features

Because only a handful of latents fire per residue, each can be traced to sequence motifs, secondary structure or tertiary contacts, and followed across depth.

Feature families

From chemistry to fold, block by block

The explorer's dictionary groups features by what they respond to. Tracking where each family peaks makes the trunk's division of labor visible: local chemistry first, secondary structure in the middle, three-dimensional organization last.

Reproduce

Train the transcoders yourself

Training streams activations straight from Boltz2 predictions, so there is no giant activation dump to manage. You need a CUDA GPU (24 GB+ recommended) and the Boltz2 checkpoint. See the technical documentation for the full pipeline.

terminal
# clone and install
git clone https://github.com/rishimj/boltz2-plt.git && cd boltz2-plt
pip install boltz[cuda] -U torch pytorch-lightning einops einx
wget https://model-gateway.boltz.bio/boltz2_conf.ckpt -O boltz2_checkpoint.ckpt

# train six per-layer transcoders on streamed activations
cd transcoder
python universal_transcoder/train_online_multi_layer.py \
    --fasta-dir ../examples/multi_protein_split \
    --checkpoint-dir ./trained_plt_checkpoints \
    --layers 0 8 16 24 32 40 --epochs 20 \
    --batch-size 10 --learning-rate 0.001 --seed 42

# reconstruction R², sparsity and dead features per layer
python validation_scripts/validate_multi_layer.py \
    --checkpoint-dir ./trained_plt_checkpoints \
    --fasta-dir ../examples/multi_protein_split \
    --layers 0 8 16 24 32 40
